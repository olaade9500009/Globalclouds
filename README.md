# Adegan95 Global Enterprise - Web Block Page

A comprehensive web development and file management platform with advanced features including intelligent code editing, real-time error detection, and user tracking.

## Features

### 🏠 Main Page (index.html)
- **Brand Identity**: Professional landing page for Adegan95 Global Enterprise
- **Owner Information**: Olawale Abdul-Ganiyu Adeshina
- **URL Generator**: Creates unique web URLs for easy sharing
- **Dropdown Menu**: Complete navigation system with all features
- **Quick Actions**: Fast access to File Manager, Code Editor, and Terminal
- **Activity Tracking**: Recent activity display
- **Console Ninja Extension**: AI-powered code assistant ready to help

### 📁 File Manager (filemanager.html)
- **Complete File Operations**:
  - Create folders and subfolders
  - Upload files (drag & drop supported)
  - Download files
  - Edit files
  - Copy, move, rename files
  - Delete files and folders
- **Grid/List View**: Toggle between different view modes
- **Folder Navigation**: Easy browsing through folder structure
- **File Type Detection**: Automatic icon assignment based on file type
- **Default Templates**: Pre-built templates for HTML, CSS, JS, JSON files
- **Persistent Storage**: All changes saved to localStorage

### 📝 Code Editor (editor.html)
- **Intelligent Error Detection**:
  - HTML syntax checking
  - CSS validation
  - JavaScript linting
  - JSON parsing
  - Common typo detection
- **Auto-Correction**: One-click fix for common errors
- **Code Formatting**: Automatic indentation and formatting
- **Live Preview**: Real-time HTML preview
- **Console Ninja Robot**: AI assistant providing suggestions
- **Syntax Highlighting**: Language-specific editor
- **Code Statistics**: Lines, characters, word count
- **Keyboard Shortcuts**: Ctrl+S to save, Ctrl+Z to undo
- **Auto-Save**: Automatic saving every 30 seconds

### 💻 Terminal & Tracking (terminal.html)
- **Real-time User Tracking**:
  - IP address tracking
  - Geographic location
  - Device type detection
  - Browser information
  - Session management
- **Command Terminal**:
  - Interactive command-line interface
  - Available commands: help, clear, status, users, logs, whoami, date, uptime, stats, export
  - System status monitoring
- **Live Statistics**:
  - Total visitors count
  - Active users
  - Total sessions
  - Average duration
- **Activity Logging**: Complete audit trail of all actions
- **Export Functionality**: Download logs as JSON

## Getting Started

### Installation
1. Simply open `index.html` in a web browser
2. All features work without any server setup
3. Data is persisted in browser's localStorage

### Navigation
- Use the dropdown menu to navigate between pages
- All pages are interconnected for seamless workflow
- Back buttons available on each page

### File Management Workflow
1. Start at **File Manager** to organize your files
2. Use **Code Editor** to edit HTML, CSS, JS files
3. Monitor activity in **Terminal**
4. Generate URLs from the **Main Page** for sharing

## Commands (Terminal)

- `help` - Show available commands
- `clear` - Clear terminal screen
- `status` - Show system status
- `users` - List active users
- `logs` - Show activity logs
- `whoami` - Display current user info
- `date` - Show current date/time
- `uptime` - Show session duration
- `stats` - Display statistics
- `export` - Export activity logs
